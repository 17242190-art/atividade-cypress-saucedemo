Automação de Testes UI e E2E com Cypress
Descrição
Projeto desenvolvido para a disciplina de Teste de Software com o objetivo de automatizar os principais fluxos da aplicação SauceDemo utilizando Cypress.

Site testado: https://www.saucedemo.com

Testes Implementados
Autenticação
Login com credenciais válidas
Login com credenciais inválidas
Carrinho
Adicionar produto ao carrinho
Remover produto do carrinho
Checkout
Fluxo completo E2E de compra
Tecnologias Utilizadas
Cypress
JavaScript
Node.js
Execução
Instalar dependências:

npm install
Executar testes:

npx cypress run
Resultado
Todos os 5 testes executados com sucesso.
